# Static Code Analysis Issues — Insurance Premium Calculator

This document records the quality, security, and logical issues identified in `premium_calculator.py` using **Pylint**, **Bandit**, **Flake8**, and manual code inspection.

## Identified Issues Table

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Tar Slip / Arbitrary File Overwrite (Bandit B202) | Security (High) | 64 | `tarfile.extractall()` is called without member path validation, allowing archives with `../` path traversal to overwrite arbitrary system files. | Validate that each tar member path stays strictly within destination folder using `os.path.commonpath` or Python 3.12+ safe `filter='data'` before extraction. |
| XML Entity Injection / XXE (Bandit B314, B405) | Security (Medium) | 7, 48 | `xml.etree.ElementTree.fromstring` is vulnerable to XML external entity expansion and quadratic blowup (Billion Laughs) DoS attacks. | Replace standard XML parser with `defusedxml.ElementTree.fromstring` to parse untrusted XML safely. |
| Insecure SSL Context Disabling Certificate Checks (Bandit B323) | Security (Medium) | 58 | `ssl._create_unverified_context()` disables SSL/TLS certificate verification and hostname checking, exposing traffic to MITM attacks. | Use `ssl.create_default_context()` to enforce full SSL certificate and hostname verification. |
| Unaudited URL Scheme in `urlopen` (Bandit B310) | Security (Medium) | 59 | `urllib.request.urlopen(url)` does not validate URL schemes, permitting unsafe schemes like `file://` or custom local schemes. | Restrict accepted schemes strictly to `http` and `https` before opening connection. |
| Insecure Hardcoded Network Binding (Bandit B104) | Security (Medium) | 12 | `HOST = "0.0.0.0"` binds the server to all network interfaces, exposing services to external untrusted networks. | Bind to `127.0.0.1` (localhost) by default and allow configuration via environment variable. |
| Predictable Insecure Temp File Location (Bandit B108) | Security (Medium) | 14 | Log file is placed at fixed path `/tmp/premium_quotes.log`, which is world-writable and prone to symlink/pre-creation attacks. | Use secure per-user temporary directory via `tempfile.gettempdir()` or configurable log directory. |
| Hardcoded Sensitive Token (Bandit B105) | Security (Low) | 13 | `UNDERWRITER_TOKEN = "uw-7f3a9c2e1b"` is hardcoded in source code in plaintext. | Load token from environment variable with fallback for development. |
| Pseudo-Random Number Generator for Identifiers (Bandit B311) | Security (Low) | 37 | `random.randint` uses the Mersenne Twister, which is cryptographically predictable and unsuitable for security-sensitive policy numbers. | Use Python `secrets` module (`secrets.SystemRandom().randint(...)`) for unpredictable policy numbering. |
| Bare `except:` Clause (Pylint W0702, Flake8 E722, Bandit B112) | Bug / Quality (Medium) | 53 | Bare `except:` catches all exceptions including `KeyboardInterrupt` and `SystemExit`, silently suppressing errors and masking bugs. | Replace with specific exceptions (`(ET.ParseError, ValueError, TypeError)`) and log unexpected errors. |
| Mutable Default Argument (Pylint W0102) | Bug (High) | 17 | `discounts=[]` default list is shared across all function invocations; `discounts.append(500)` mutates it, corrupting future quote calculations. | Set default to `None` and initialize `discounts = list(discounts) if discounts is not None else []` inside the function. |
| Logic Bug: String Smoker Value Falsely Truthy | Bug (Medium) | 22 | `if smoker:` evaluates `"no"` to `True` because any non-empty string in Python is truthy, charging non-smokers a 30% smoker surcharge. | Convert input boolean properly, checking if `str(smoker).lower() in ("true", "1", "yes")`. |
| Logic Bug: Negative Premium Calculation | Bug (Medium) | 25 | Applying multiple stacked discounts can produce a negative premium (e.g. `-800.0`), which is actuarially invalid. | Enforce minimum floor `premium = max(premium, 0.0)`. |
| Logic Bug: Birthday Age Calculation Off-by-One | Bug (Medium) | 33 | `today.year - born.year` fails to account for whether the applicant's birthday has passed in the current calendar year. | Account for current month and day: `today.year - born.year - ((today.month, today.day) < (born.month, born.day))`. |
| Logic Bug: Leap Year Crash on Renewal Calculation | Bug (Medium) | 80 | `date.replace(year=date.year + years)` raises `ValueError` when renewing policies on February 29 of a leap year. | Handle leap year edge case by adjusting to February 28 when target year is not a leap year. |
| Unclosed File Handle & Missing Encoding (Pylint R1732, W1514) | Quality (Low) | 42-44 | File `open()` is called without context manager `with` and without explicit `encoding="utf-8"`, risking resource leaks and encoding bugs. | Refactor to `with open(..., encoding="utf-8") as f:`. |
| Non-PEP 8 Naming Conventions (Pylint C0103) | Style (Low) | Multiple | Function names use camelCase (`calculatePremium`, `ageFromDob`, etc.) instead of PEP 8 snake_case (`calculate_premium`, etc.). | Rename functions to snake_case and provide alias wrappers to maintain backward compatibility. |
| Missing Module and Function Docstrings (Pylint C0114, C0116) | Quality (Low) | 1, 17, 30+ | Missing docstrings explaining module and function parameters, return values, and behaviors. | Add comprehensive PEP 257 docstrings to module and every function. |
| Overly Long Lines and Whitespace Violations (Flake8 E501, E302, E305) | Style (Low) | Multiple | Multiple lines exceed 79/100 characters and top-level functions lack standard two blank lines separation. | Reformat code to respect PEP 8 line length (<=79 chars) and standard blank line formatting. |
| Simplifiable `if` and Redundant `else` (Pylint R1703, R1705) | Quality (Low) | 68, 74 | `if cond: return True else: return False` is redundant and can be replaced with direct boolean expressions. | Simplify to `return token == UNDERWRITER_TOKEN` and remove unnecessary `else` after `return`. |
